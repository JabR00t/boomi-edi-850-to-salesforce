# Setup Guide

This guide describes how to recreate the Boomi EDI X12 850 to Salesforce integration.

## Prerequisites

- Boomi Integration account
- Boomi runtime / Atom
- Salesforce Developer Edition
- Salesforce REST API access
- Git
- Sample X12 850 file

## 1. Create the Disk Connection

Create a Boomi Disk connection:

`CONN - Disk - Inbound EDI 850`

Example directory:

`/boomi/projects/edi850/inbound/`

Create a Disk Query operation:

`OP - Disk - Query EDI 850 Files`

Configure the filename filter as:

`fileName WILDCARD ?`

Supply:

`*.edi`

from the process.

## 2. Create the X12 850 Profile

Create an EDI profile using:

- Standard: X12
- Version: 4010
- Transaction: 850 Purchase Order

Import the following main segments:

- ST
- BEG
- N1
- PO1
- CTT
- SE

Configure delimiters:

- Element delimiter: `*`
- Segment terminator: `~`
- Composite delimiter: `>`

## 3. Configure N101 Qualifiers

On:

`N1 Loop -> N1 -> N101`

import the following qualifier values:

| Code | Meaning |
|---|---|
| BT | Bill-to-Party |
| ST | Ship To |
| SF | Ship From |

## 4. Configure N1 Loop Instance Identifiers

Create the identifiers at the **N1 Loop level**:

- `N1 Loop [N101=BT]`
- `N1 Loop [N101=ST]`
- `N1 Loop [N101=SF]`

This allows the associated N1, N3 and N4 segments to be treated as one qualified party/address loop.

## 5. Configure Salesforce

Create the custom object:

`Purchase_Order__c`

Fields:

| Field | Type |
|---|---|
| Name | Text |
| Order_Date__c | Date |
| Bill_To_Name__c | Text |
| Bill_To_City__c | Text |
| Ship_To_Name__c | Text |
| Ship_To_City__c | Text |
| Ship_From_Name__c | Text |

## 6. Configure Salesforce Permissions

Create a permission set:

`Boomi Salesforce Integration`

Grant the integration user:

- Read
- Create
- Edit

for `Purchase_Order__c`.

Also grant field-level Read/Edit access to the custom fields.

## 7. Configure Salesforce OAuth

Use the Salesforce REST connector with OAuth 2.0 Client Credentials.

The Salesforce External Client App must have Client Credentials enabled and a Run As user configured.

Boomi configuration:

```text
Authentication Type: OAuth 2.0
Grant Type: Client Credentials
Client ID: <Consumer Key>
Client Secret: <Consumer Secret>

Access Token URL:
https://<your-my-domain>/services/oauth2/token

Service URL:
https://<your-my-domain>/services/data/v67.0

```

## 8. Create the Salesforce Operation

Create:

`OP - Salesforce REST - Create Purchase Order`

Configuration:

```text
Action: Create
Object: Purchase_Order__c
```

Boomi generates the Salesforce request profile automatically.

## 9. Create the Map

Create a new Boomi Map component:

`MAP - X12 850 to Salesforce Purchase Order`

### Source Profile

Use:

`PROFILE - X12 850 Purchase Order`

### Destination Profile

Use the Salesforce profile generated by the Salesforce REST Create operation:

`Salesforce REST Purchase_Order__c CREATE Request`

### Field Mappings

Configure the following mappings:

| X12 850 Source | Salesforce Destination |
|---|---|
| `BEG03` | `Name` |
| `BEG05` | `Order_Date__c` |
| `N1 Loop [N101=BT] → N1 → N102` | `Bill_To_Name__c` |
| `N1 Loop [N101=BT] → N4 → N401` | `Bill_To_City__c` |
| `N1 Loop [N101=ST] → N1 → N102` | `Ship_To_Name__c` |
| `N1 Loop [N101=ST] → N4 → N401` | `Ship_To_City__c` |
| `N1 Loop [N101=SF] → N1 → N102` | `Ship_From_Name__c` |

### Date Conversion

The X12 850 `BEG05` date is represented as:

```text
20260905
```

Salesforce expects a Date value in this format:

```text
2026-09-05
```

Add a Boomi **Date Format** map function between `BEG05` and `Order_Date__c`.

Configure:

```text
Input Mask:  yyyyMMdd
Output Mask: yyyy-MM-dd
```

The mapping becomes:

```text
BEG05
  |
  v
Date Format
yyyyMMdd -> yyyy-MM-dd
  |
  v
Order_Date__c
```

## 10. Build the Main Boomi Process

Create the main process:

`PROC - Inbound EDI 850 to Salesforce`

The process contains four main shapes:

```text
Start - Disk Query
        |
        v
       Map
        |
        v
Salesforce REST Create
        |
        v
       Stop
```

### Disk Start Shape

Configure the Start shape with:

```text
Connector: Disk
Connection: CONN - Disk - Inbound EDI 850
Operation: OP - Disk - Query EDI 850 Files
```

Supply the query parameter:

```text
fileName:WILDCARD = *.edi
```

### Map Shape

Select:

`MAP - X12 850 to Salesforce Purchase Order`

### Salesforce REST Connector Shape

Configure:

```text
Connector: Salesforce REST
Action: Create
Connection: CONN - Salesforce REST
Operation: OP - Salesforce REST - Create Purchase Order
```

### Stop Shape

Add a Stop shape after the Salesforce REST connector.

## 11. Prepare the Test EDI File

Create:

`sample-data/inbound/PO_850_001.edi`

with the following content:

```text
ST*850*0001~
BEG*00*SA*PO12345**20260905~
N1*BT*ABC CORPORATION~
N3*100 MAIN STREET~
N4*NEW YORK*NY*10001~
N1*ST*ABC WAREHOUSE~
N3*500 INDUSTRIAL ROAD~
N4*CHICAGO*IL*60601~
N1*SF*XYZ FACTORY~
N3*20 FACTORY ROAD~
N4*DETROIT*MI*48201~
PO1*1*10*EA*25.00**VN*ITEM001~
PO1*2*5*EA*50.00**VN*ITEM002~
CTT*2~
SE*15*0001~
```

Copy the file into the directory configured in the Boomi Disk connection.

Example:

```text
/boomi/projects/edi850/inbound/
```

## 12. Test the Integration

Run the process in Boomi Test mode.

A successful execution should follow this path:

```text
EDI File
   |
   v
Disk Query
   |
   v
X12 850 Profile
   |
   v
N101 Qualifiers
   |
   v
N1 Loop Instance Identifiers
   |
   v
Boomi Map
   |
   v
Salesforce REST
   |
   v
Purchase_Order__c
```

The Boomi execution should complete successfully with the Salesforce REST connector creating a record.

## 13. Verify the Salesforce Record

Open Salesforce Developer Console and run the following SOQL query:

```sql
SELECT Name, Order_Date__c, Bill_To_Name__c, Bill_To_City__c, Ship_To_Name__c, Ship_To_City__c, Ship_From_Name__c FROM Purchase_Order__c WHERE Name = 'PO12345'
```

Expected values:

| Salesforce Field | Expected Value |
|---|---|
| `Name` | `PO12345` |
| `Order_Date__c` | `2026-09-05` |
| `Bill_To_Name__c` | `ABC CORPORATION` |
| `Bill_To_City__c` | `NEW YORK` |
| `Ship_To_Name__c` | `ABC WAREHOUSE` |
| `Ship_To_City__c` | `CHICAGO` |
| `Ship_From_Name__c` | `XYZ FACTORY` |

## 15. Security Notes

Do not commit any of the following to GitHub:

- Salesforce Client Secret
- OAuth access tokens
- Salesforce passwords
- Boomi credentials
- Private keys
- Environment-specific secrets

Use placeholders in documentation, for example:

```text
Client ID: <SALESFORCE_CLIENT_ID>
Client Secret: <SALESFORCE_CLIENT_SECRET>
Salesforce Domain: https://<your-domain>.my.salesforce.com
```
